Integra Dental NC Partial Extraction

Restart the cut.Not the whole job.

When a mill stops halfway through a long zirconia job, you should not have to go back to CAM, recalculate every toolpath and run roughing again. This tool edits the program you already have: it writes a new file that starts where you need it, with the machine state the original had at that point, and checks it before it saves.

The problem

Two ways back from a stop.Only one reruns the whole case.

An air pressure alarm, a broken tool or a power cut leaves a program half done. The usual fix treats it as new work. This tool treats it as an edit.

Back to CAM

Recalculate and repost the whole job

  1. Open the case again in CAM
  2. Recalculate every toolpathThe CAM station is busy for the full calculation again.
  3. Post a new NC file
  4. Transfer it, reload it, check offsets
  5. Run T1 roughing againIn air if you are lucky, in material if you are not.
  6. Finally reach line 482,113 again

Everything before the alarm runs again.

Integra Dental NC Partial Extraction

Edit the program you already have

  1. Map the program into tool phases and operations
  2. Pick the restart line, block number, phase or operation
  3. Write the partial programPreamble, tool change, restored state, safe approach, original toolpath unchanged, clean end.
  4. Verify its state against the originalNothing is saved if anything differs.
  5. Air cut, then resume cutting

About 16 seconds for a million line program in our tests.

  • Original preambleProgram number, units, plane and anything machine specific, copied as is.
  • The phase's own tool changeT2, spindle, coolant and length offset exactly as the CAM post wrote them.
  • State the original had at that pointWork offset set by an earlier tool, a speed changed mid phase, coolant, feed and motion mode.
  • Safe approachRetract to your own machine Z, turn the rotary axes up there, position X and Y, then come down in Z.
  • Original toolpath, byte for byteStarting from the last rapid move before the stop, so the tool comes in the way CAM planned it.
  • Clean endRetract, M5, M9 and M30 when your selection does not already include the program end.

What you can ask for

Four everyday jobs.One file you already have.

  1. 01

    Restart after a stop

    From a line or a block number to the end, or only to the end of the phase.

    restart JOB.nc --block 48210
  2. 02

    Run one tool

    Rerun a finishing tool, or one phase of several, without the others.

    extract JOB.nc --tool T2
  3. 03

    Run one operation

    The final support cut off pass so the parts drop, or any operation CAM named.

    extract JOB.nc --op-match support
  4. 04

    Check a file that won't load

    Missing M30, code after the end, stray characters, mixed line endings.

    check JOB.nc
With the skill installed You do not type these. Tell Claude what happened at the machine and it maps the file, asks what it needs, runs the tool and walks you through the prove out.

Safety

Built to refuse a bad restart.And to say why.

Checks on every file

  • Simulates the new program and compares units, plane, work offset, tool, length offset, spindle, coolant, feed, motion mode and every axis position with the original at the restart point.
  • Copies the original toolpath lines unchanged and confirms it did.
  • Never overwrites your source file.
  • Keeps your line endings and always writes a decimal point in the moves it adds.

Refuses, and explains

  • A restart inside G91 incremental moves.
  • A restart inside an active drilling cycle.
  • A restart with cutter compensation on.
  • A restart with coordinate rotation, scaling, G52 or G92 active.
  • A restart with no safe retract known, until you give one.

Always prove it out. Open the new program in your CAM simulator first. Confirm the work offset, tool and length offset match the original job. Run it as an air cut with the feed override low and a hand on feed hold, and watch the first approach move.

Install

Free and MIT licensed.No dependencies.

Claude Code

Add the marketplace and install the plugin.

/plugin marketplace add pman7/integra-dental-nc-partial-extraction
/plugin install integra-dental-nc-partial-extraction@integra-dental

Claude apps

Zip the skills/integra-dental-nc-partial-extraction folder and upload it as a skill in Claude's settings, under Capabilities. Code execution must be on.

Command line

Python 3.8 or newer, standard library only.

python3 skills/integra-dental-nc-partial-extraction/scripts/nc_extract.py map JOB.nc
